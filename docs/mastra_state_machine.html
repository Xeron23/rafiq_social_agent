01. IngestContextStep & Strategy Analysis
Mastra Agent + Tool
Trigger / Input userChatIntent + projectId
Aksi Mastra Agent memanggil trendListeningTool untuk scraping data tren dan memadukan dengan ICP di Project Context Store.
Data Output TrendReport + CampaignBrief
02. Content Planning & Canonical Drafting Step
Mastra Workflow Step
Input CampaignBrief + Pilar
Aksi Mastra Memetakan kalender 15 slot topik & menyusun Raw Canonical Content (Tesis, Bank 5 Hooks, Argumen Logis, Data Fakta, CTA).
Data Output TopicMapping[] + CanonicalDraft[]
03. SuspendForHITLGate (Human-in-the-Loop Checkpoint)
Workflow Suspended
State Mesin state: SUSPENDED
Mekanisme Interaksi Mastra membekukan eksekusi. User meninjau tabel topik & raw draft di UI. Bisa mutasi chat ("revisi hook") atau klik 1-Click Approve.
Resume Trigger workflow.resume(runId, APPROVED)
04. MultiPlatformAdapterStep (Parallel Compilers)
Parallel Step
Input Approved CanonicalDraft
Aksi Mastra Mengeksekusi compiler deterministik paralel: X (≤280 karakter), LinkedIn profesional, IG Carousel slide, dan Medium markdown.
Data Output CompiledPlatformPayloads[]
05. Scheduling & Dispatch Queue Step
Queue & DB Lock
Input CompiledPlatformPayloads
Aksi Mastra Menyimpan payload siap rilis ke DB dengan status SCHEDULED dan mendaftarkan jadwal ke cloud timer untuk rilis otonom 24/7.
Eksekusi Rilis Dipublish tepat waktu ke API Medsos
