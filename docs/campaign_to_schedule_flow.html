Tahapan Alur Kerja Rinci (Lifecycle Breakdown)

1. Campaign Initiation & User Intent Fase Hulu
Interaksi dimulai dari chat brief kampanye (misal: "Peluncuran Fitur X untuk Tech Lead selama 14 hari"), bukan langsung loncat menulis topik acak.
2. Context & Strategy Analysis (Mastra Tool) Fase Riset
Mastra Agent membaca Project Context Store (ICP, Brand Tone, Pilar) dan menjalankan tool riset tren pasar/sosial untuk memvalidasi sudut pandang audiens.
3. Content Planning Formulation Fase Perencanaan
Menghasilkan arsitektur rencana kampanye: distribusi frekuensi rilis, fokus pesan tiap pilar, dan target channel distribusi yang dituju.
4. Topic Mapping & Canonical Drafting Fase Sintesis Raw
Memetakan slot jadwal menjadi topik konkret, lalu mensintesis Canonical Content (Raw Master): membedah Tesis Utama, Bank Variasi Hook, Argumen Inti, Data Fakta, dan CTA tanpa batas format platform.
🛑 5. Human-in-the-Loop (HITL) Checkpoint Gate Validasi
User meninjau Topic Mapping & Canonical Draft. User bisa meminta revisi sudut pandang / argumen via chat. Setelah dirasa pas, user memberikan 1-Click Approval.
6. Deterministic Multi-Platform Adaptation Fase Kompilasi
Canonical Draft yang sudah di-approve diadaptasi secara deterministik ke format spesifik: X (≤280 karakter), LinkedIn (long-post), IG Carousel (slide-by-slide), dan Medium.
⏰ 7. Scheduling & Dispatch Queue POSISI SCHEDULING
Di sinilah letak Scheduling: Payload postingan yang telah terkompilasi dikunci bersama jadwal kalendernya ke dalam antrean (Scheduler). Sistem mengeksekusi rilis ke API medsos secara tepat waktu tanpa perlu intervensi manual lagi.
8. Closed-Loop Analytics & Context Feedback Fase Evaluasi
Menarik metrik performa pasca-posting (impresi, engagement) dan menginjeksi rekomendasi baru ke Project Context Store untuk kampanye berikutnya.
