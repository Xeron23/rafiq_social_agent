Detail Langkah Alur Kerja Mastra AI Agent (Flow Breakdown)

  1. Fase 1: Context Ingestion & Trend Tooling
    Worker menginisialisasi agent Mastra dengan konteks terisolasi dari Project Context Store (ICP & Pilar). Mastra memicu TrendListeningTool untuk meriset tren web & medsos terkini secara otonom.
  2. Fase 2: Campaign Brief & Matrix Formulation
    Mastra mensintesis intent percakapan user dan hasil riset tren menjadi CampaignBrief. Selanjutnya, agent menghasilkan batch ContentPlanMatrix (daftar 5–15 topik, hook awal, target pilar, dan tanggal publikasi).
  3. Fase 3: Macro Human-in-the-Loop (HITL) Checkpoint
    Pipeline Mastra masuk ke status Suspended / Awaiting Approval. User cukup meninjau matriks tabel di dashboard dan memberikan 1-Click Macro Approval (atau request mutasi sudut pandang via chat).
  4. Fase 4: Canonical Content Engine (Single Source of Truth)
    Setelah disetujui, Mastra menjalankan sintesis Canonical Content (konten mentah berbobot tinggi berisi tesis inti, multi-angle hooks, argumen logis, data pendukung, dan CTA) tanpa batasan format platform.
  5. Fase 5: Deterministic Multi-Platform Adapters & Distribution
    Mastra secara paralel mentransformasikan Canonical Content ke format tujuan: X (≤280 karakter), LinkedIn (struktur profesional), Instagram (slide carousel + visual prompt), dan Medium (long-form markdown). Postingan dieksekusi ke API target.
  6. Fase 6: Closed-Loop Analytics & Self-Improvement
    Mastra menarik metrik performa pasca-rilis, mengevaluasi efektivitas hook, dan menginjeksi insight baru ke Project Context Store untuk kampanye masa depan.

Prinsip Canonical Content ("Raw Material")

Berperan sebagai fondasi intelektual konten sebelum dibentuk ke wadah media sosial. Mencegah constraint bleed (kebocoran aturan format antar platform) dan menjamin kedalaman substansi tulisan.

Isolasi Worker & Project Context

Application Worker hanya memiliki akses terisolasi ke Project Context miliknya sendiri. Tidak ada data sharing atau percampuran memori antar brand maupun antar project dalam multi-tenant store.
